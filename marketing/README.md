# Marketing Operations Memory

운영을 재개할 때 아래 순서만 따릅니다.

1. `current-state.json`을 읽습니다.
2. Meta, GA4, Google Form의 바뀐 숫자만 확인합니다.
3. `snapshots.jsonl`에 새 관측값을 추가합니다.
4. 분석 보고서를 다시 생성합니다.
5. `current-state.json`을 최신값으로 교체합니다.

`marketing-history.md`와 `archive/`는 과거 결정의 이유를 조사할 때만 읽습니다.
일상 점검에서 전체 대화나 전체 이력을 다시 읽지 않습니다.
